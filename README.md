# 屏幕文字朗读器（ScreenReader）

读取电脑屏幕上「指定矩形区域」的文字，按角色/情绪选择不同语音包，
**有感情地实时朗读出来**。

---

## 一、它能做什么

1. **读指定区域的文字**：用鼠标在屏幕上框一块区域，程序自动识别里面的文字并朗读。
2. **按说话人身份换语音**：再框一块「身份区域」。程序读取该区域的文字
   （比如出现「小女孩」「开心」等词），自动判断用哪个语音包来读。
3. **图形界面**：选择语音包 / 语言、框选两个区域、开始停止，点点鼠标就行。
4. **实时朗读**：每几秒自动识别一次，文字变了才读，不重复啰嗦。

## 二、目录结构（新手先看这个）

```
ScreenReader/
├── main.py                 # 程序入口，双击/运行它启动
├── config.py               # ★所有可配置项都在这里（语音包、判断规则、语速…）
├── requirements.txt        # 需要安装的第三方库
├── modules/                # 功能模块（每个文件只干一件事）
│   ├── capture.py          # 截图 + 鼠标框选
│   ├── ocr.py              # 图片 → 文字（OCR）
│   ├── tts.py              # 文字 → 语音（朗读）
│   └── voice_chooser.py    # 根据文字判断用哪个语音包
└── ui/
    └── app.py              # 图形界面
```

**每个文件顶部都有中文注释**，说明这个文件是干什么的、怎么用。

## 三、安装与运行

### 1. 安装依赖
```powershell
cd C:\Users\12579\ScreenReader

```

> 说明：
> - `easyocr` 第一次运行时会**联网下载识别模型**（约几十 MB），请耐心等待，只需一次。
> - 如果安装 `easyocr` 出错，通常是它依赖的 `torch` 版本问题，
>   可先单独执行 `pip install torch torchvision` 再装 `easyocr`。

### 2. 运行
```powershell
python main.py
```

## 四、界面使用步骤

1. **选择语音包**：下拉框里选一个，点「试听」能听到效果。
2. **选择语言**：中文选 `ch_sim+en`，纯英文选 `en`。
3. **框选身份区域**：点按钮 → 屏幕变暗 → 鼠标拖一个框 → 松开。
   （框住会出现「小女孩」「开心」等身份提示词的地方）
4. **框选文字区域**：同上，框住你要朗读的那段文字。
5. 点 **▶ 开始朗读**，程序就会每隔几秒自动识别并朗读。
   也可以点 **🔊 立即朗读一次** 单次触发。

> 你框的选区会自动保存到 `user_settings.json`，下次打开还在。

## 五、★ 如何扩展（新手重点）

### 场景 A：新增一个语音包
打开 `config.py`，在 `VOICE_PACKS` 里加一段：

```python
"机器人": {
    "rate": 180,
    "volume": 1.0,
    "voice_keywords": ["Zira", "Female"],   # 想用的系统音色关键词
},
```
保存后重新运行，界面下拉框里就会出现「机器人」。

- `rate`：语速，越大越快（100~300）。
- `volume`：音量，0.0~1.0。
- `voice_keywords`：想用系统里哪个音色，填它名字里的关键词；
  留空 `[]` 就用系统默认声音。

> 想知道系统里有哪些音色？运行一次程序后，看控制台，
> 或在 `tts.py` 的 `list_system_voices()` 里打印看看。

### 场景 B：改「按什么词判断说话人」
打开 `config.py` 的 `SPEAKER_RULES`：

```python
SPEAKER_RULES = [
    (["哭", "叹气", "难过"], "消沉的男人"),     # 出现这些词 → 用消沉的男人
    (["哈哈", "开心"], "开心的男孩"),
    ...
]
```
- 每行是 `(关键词列表, 语音包名字)`。
- **从上往下**匹配，第一条命中的生效，所以把重要的放上面。
- 关键词列表可以随便加。

### 场景 C：换成更自然的真人语音（进阶）
现在用的是系统自带语音（调语速/音量来区分情绪）。
想要更逼真的「有感情」声音，推荐 `edge-tts`（免费、微软真人有感情音色）：

```powershell
pip install edge-tts playsound
```
然后只需把 `modules/tts.py` 里的 `speak()` 换成用 edge-tts 播放，
其它代码完全不用动（因为大家统一调用 `speak(text, pack)`）。

也可以在语音包里加一个字段 `"edge_voice": "zh-CN-XiaoxiaoNeural"`，
朗读时优先用它。

### 场景 D：加更多识别语言
在 `ui/app.py` 的 `lang_choices` 列表里加，例如加日语 `ja`、韩语 `ko`
（需 EasyOCR 支持，具体见其官方文档）。

## 六、常见问题

| 问题 | 解决 |
|------|------|
| 第一次运行特别慢 | EasyOCR 在下载模型，等它下完即可 |
| 没声音 | 检查系统音量；`pip install pyttsx3` 是否成功 |
| 识别不准 | 框小一点、只框文字；或把字体放大后再框 |
| 提示 torch 相关错误 | `pip install torch torchvision` 后重装 easyocr |
| 框选时看不到屏幕 | 程序会自动隐藏主窗口，框完会自动恢复 |

## 七、代码可读性设计说明

- **一个文件一件事**：截图、识别、朗读、判断、界面各自独立，方便单独改。
- **配置集中管理**：想调参数只改 `config.py`，不用翻遍代码。
- **模块之间通过简单接口通信**：
  - `capture.grab(box)` → 图片
  - `TextReader.read_text(图片)` → 文字
  - `choose_voice_pack(文字)` → 语音包
  - `Speaker.speak(文字, 语音包)` → 发声
  只要保持这些「接口」不变，内部怎么改都不影响其它模块。
